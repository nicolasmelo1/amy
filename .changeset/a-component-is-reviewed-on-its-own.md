Plans a design system for the window, with one `npm run design` at the root
that opens every platform's catalogue or only the ones named. It also records
that the frame stays the core's: a plugin changes how a section is seen and
how it looks, never where the regions are. Nothing published changes.

The workplace plan offers every mounted opener from one *Open in* menu: each
harness plugin brings its own, the diff opens against its base in the
person's diff tool, and the embedded terminal is ghostty-web.
